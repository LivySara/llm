# 抽奖九宫格（后端出数组、无 rotate、正方形格子、指定点位停止）

## 一、硬性约束
- **禁止** 用 CSS `rotate` 旋转整个九宫格容器。
- 只允许做「格子高亮切换」动画（边框放大、阴影、变色）。
- 格子为**正方形**，中心为抽奖按钮（不参与滚动），外围 8 格走滚动高亮。
- 中奖结果由**后端把控**：前端不能篡改。

## 二、整体流程
1. 用户点击抽奖按钮。
2. 前端请求后端接口。
3. 后端返回：
   - 奖品数组（`prizes`）
   - 最终中奖格子的**索引 `target`**（中奖逻辑全在后端）
4. 前端执行高亮轮播动画：
   - 前期快速循环高亮 → 中期匀速 → 后期减速逼近 `target`
   - 最终**定格**在后端指定的中奖格子。
5. 弹出中奖弹窗。

## 三、无 rotate 核心实现原理
- 布局：用 `Grid` / `Flex` 摆出 3×3 正方形格子，中心放大按钮，外围 8 格。
  - **正方形保证（自适应宽度）核心原则**：高度必须由宽度推导，禁止写死 `px` 高度。常用方案：
    1. **容器正方法（最推荐/最亮眼）**：外层容器 `aspect-ratio: 1/1` + `grid-template-rows: repeat(3,1fr)`，3×3 均分后 9 格天然正方，单格无需再设。
       ```css
       .grid { display:grid; grid-template-columns:repeat(3,1fr); grid-template-rows:repeat(3,1fr);
               gap:8px; width:min(90vw,360px); aspect-ratio:1/1; }
       ```
    2. **单格 `aspect-ratio:1`（现代首选）**：`grid-template-columns:repeat(3,1fr)` + 每格 `aspect-ratio:1/1`。
    3. **padding 撑高（老浏览器）**：`.cell{position:relative;height:0;padding-top:100%}` + 内容 `position:absolute;inset:0`。
    4. **容器查询 `cqw`（组件化复用）**：`.grid{container-type:inline-size}` + `.cell{width:30cqw;aspect-ratio:1}`。
    5. **JS 动态测量（ResizeObserver）**：监听容器宽，设每格 `height = clientWidth/3`，兼容性 100%。
    6. **`clamp()`+`vw` 流式封顶**：`width/height: clamp(80px,28vw,120px)`，同表达式保证正方。
    7. **`vmin` 视口单位 / SVG `viewBox`**：适合全屏居中或需无损缩放场景。
  - 选型速查：现代项目→容器 `aspect-ratio`；每格独立控→单格 `aspect-ratio`；老浏览器→padding/JS；组件化→`cqw`；流式→`clamp`。
- 预定义**顺时针（或逆时针）遍历路径数组** `path = [0..7]`（路径顺序 ≠ 视觉下标，需按顺时针排序）。
- 用 `setInterval` 定时器循环修改「当前高亮索引 `current`」：
  - 给 `path[current]` 对应格子加 `active` 高亮样式；
  - 其余格子移除 `active`。
- 速度变化只改定时器 **interval 时长**，不改任何 transform 旋转。

## 四、变速逻辑（关键）
- **前几圈**：interval 短（如 60ms），快速轮播。
- **最后 2 圈**：逐步拉长 interval（如 60 → 100 → 180 → 300ms），缓慢逼近。
- **步数计算**：已知起点、路径总长、`target`：
  - 计算需要走的总步数，使 `current` 正好落在 `target`；
  - 到达后 `clearInterval` 停止定时器，触发弹窗。
- 核心是「**先算总步数 + 末段减速**」，保证落点精准，避免越界或抖动。

## 五、中心中奖兼容
- 外围格子走到临近位置（末段）后，单独触发**中心格子高亮**，作为「中奖爆发」视觉收尾，再弹窗。

## 六、面试要点（谈资）
- 为什么后端出 `target`：防前端篡改、保证公平性、活动可控（概率/库存）。
- 为什么不用 rotate：`rotate` 只能整体转，落点难精准控制，且不利于无障碍/可访问性；高亮切换更易做变速与键盘焦点。
- 边界处理：定时器必须能 `clearInterval`，页面卸载/快速连点要加锁（抽奖中禁止重复点击）。
- 可扩展：路径数组抽离，支持 N×N；减速曲线可用 ease 函数替代分段常量。
