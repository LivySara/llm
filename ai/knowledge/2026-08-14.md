# LLM在agent中承担的不同职责

- 理解目标
- planing [规划]
- decision making [决策]
- tool selection [工具选择]
- reasoning [推理]
- result evaluation [解决评估]

# 记忆是agent组成之一

- 短期记忆放在context window里，存在当前任务的中间状态
- 长期记忆用向量数据库实现，能跨任务保存用户偏好和历史

# 工具选择由LLM决定，工具执行由agent决定

- LLM本身不负责执行工具，LLM根据系统提供的Tool Schema(agent提供)，输出Tool Call, 即工具名和参数
- Agent Runtime 接收到这个决策后，负责参数校验、权限控制以及实际调用工具，工具执行结果再返回给 LLM，由 LLM 决定下一步动作
- 目的：实现了决策和执行的分离，也避免让模型直接拥有系统执行权限

# agent loop 定义

- 把[决策 - 执行 - 结果 - 再决策] 循环起来
