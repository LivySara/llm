# React 性能优化实验室（react-lab）

一个**专门用来练手性能优化**的 React 项目：里面的代码全部是「故意写错」的，先复现卡顿，再按提示动手优化。

技术栈：Vite 5 + React 18 + TypeScript。

## 启动

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # 类型检查 + 产物构建
```

## 界面说明

- 左侧：按分类（渲染 / 计算 / 布局动画 / 内存 / 网络 / 构建体积）列出案例，带难度标记。
- 右侧上半：可交互的问题现场（按钮、滑块、输入框），顶部有实时指标（FPS、渲染次数、渲染耗时）。
- 右侧下半：每个案例的「如何复现 / 可观察现象 / 根因 / 优化清单 / 验收标准」，照着做即可。

## 推荐练习流程

1. 打开案例，先按「如何复现」操作，用 Chrome Performance / React DevTools Profiler 记录一次基线数据。
2. 阅读「根因」，定位到源码里标了 🐛 的那几行。
3. 按「优化清单」改代码（建议新开分支，保留坏版本方便对比）。
4. 再录一次数据，对照「验收标准」确认收益。

> 提示：项目刻意关闭了 `StrictMode`，避免开发环境的双次渲染干扰渲染次数统计。
