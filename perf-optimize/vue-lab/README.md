# Vue 性能优化实验室（vue-lab）

一个**专门用来练手性能优化**的 Vue 3 项目：代码全部「故意写错」，先复现卡顿，再按提示动手优化。

技术栈：Vite 5 + Vue 3（`<script setup>` + TS）。

## 启动

```bash
npm install
npm run dev      # http://localhost:5273
npm run build    # 产物构建
```

## 界面说明

- 左侧：按分类（渲染 / 响应式 / 计算 / 布局动画 / 内存 / 构建体积）列出案例，带难度标记。
- 右侧上半：可交互的问题现场（按钮、滑块、输入框），顶部有实时指标（FPS、更新次数、更新耗时）。
- 右侧下半：每个案例的「如何复现 / 可观察现象 / 根因 / 优化清单 / 验收标准」。

## 推荐练习流程

1. 打开案例，按「如何复现」操作，用 Chrome Performance / Vue DevTools 的 Performance 面板记录基线。
2. 阅读「根因」，定位源码里标了 🐛 的位置。
3. 按「优化清单」改代码（建议新开分支，保留坏版本方便对比）。
4. 再录一次数据，对照「验收标准」确认收益。
