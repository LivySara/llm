- Node 是 JS 单线程，不等于 Node 进程只有一个线程。
- JavaScript 代码主要由一个主线程执行
- 主线程负责执行 JS，Event Loop 负责安排异步任务，Node 底层负责处理一些耗时工作。

```
程序文件
   ↓
运行起来
   ↓
进程
   ↓
里面有线程
```

```
进程：隔离资源
线程：执行代码
Node：JS 主线程执行 JS
child_process：创建另一个进程
```

```
进程 = 容器 / 隔离单位

线程 = 干活的执行单位

child_process = 开一个新容器

worker_threads = 在当前容器里增加一个干活的人
```

```
event loop 执行规则：

① 执行同步代码
        ↓
② 清空微任务
        ↓
③ 执行一个宏任务
        ↓
④ 清空微任务
        ↓
⑤ 执行一个宏任务
        ↓
⑥ ...
```
> 微任务：promise.resolve().then(() => {})
> 宏任务：setTimeout(() => {})
