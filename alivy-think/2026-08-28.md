# 要点

- mysql关键点
```
MySQL
 │
 ├── 数据库 / 表 / 字段 [✔]
 ├── CRUD [✔]
 ├── WHERE [✔]
 ├── ORDER BY [✔]
 ├── GROUP BY [✔]
 ├── JOIN ⭐ [✔]
 ├── 索引 ⭐
 ├── 事务 ⭐
 └── 数据库设计 ⭐
```
- SQL 是一种“语言”，MySQL / PostgreSQL / SQLite 是“关系型数据库”，MongoDB 是另一种数据库类型，Redis / Memcached 更偏“缓存”。
> sql 是一套操作关系数据库的语言，给 MySQL / PostgreSQL / SQLite 执行

- inner join 与 left join 区别
> INNER JOIN：我要两边都有的数据。
> LEFT JOIN：左边的数据我一个都不能丢。

- 学习方式
```
知识点
↓
它解决什么问题？
↓
什么现象会触发它？
↓
和哪些知识一起使用？
↓
真实问题中自己调用
```
