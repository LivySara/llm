# 学习笔记：Transformer 架构（2026-09-04 16:57）

## 一、一张图记住整套架构

```
Token Embedding + Position(RoPE)
        │
        ├── RMSNorm ──→ Self-Attention (Q/K/V + 因果掩码) ──→ + (残差)
        │                    ↑ 负责「token 之间的通信」
        ├── RMSNorm ──→ FFN (SwiGLU 门控)              ──→ + (残差)
        │                    ↑ 负责「token 内部的计算/知识」
        ▼
   × 24~80 层 ──→ RMSNorm ──→ LM Head ──→ 下一个 token 的概率
```

**一句话本质**：Transformer = 一个**可微的、内容寻址的并行数据库**。序列既是「查询者」也是「被检索的行」，`softmax(QKᵀ/√d_k)V` 就是一次带软权重的批量字典查找。

---

## 二、每个组件「到底在解决什么问题」

| 组件 | 解决的问题 | 不这么做会怎样 |
|---|---|---|
| Self-Attention | RNN 的串行依赖 → 无法并行、长距离梯度衰减 | 训练随序列长度线性变慢，远处信息丢失 |
| Q / K / V 三分 | 解耦「怎么被找到(K)」和「找到后给什么(V)」 | 检索特征与内容特征被迫共用同一向量 |
| 除以 √d_k | 多源点积的**方差累积** → softmax 饱和 → 梯度消失 | d_k 大时训练直接停滞 |
| Multi-Head | 一组 QKV 只能表达一种「相关性定义」 | 「苹果→好吃」和「苹果→主语」无法同时捕捉 |
| FFN / SwiGLU | Attention 只做信息搬运，不做非线性变换与知识存储 | 模型只有路由没有计算 |
| 位置编码 (RoPE) | Attention 对顺序完全不敏感（打乱输入结果不变） | 「我打你」==「你打我」 |
| Pre-LN | Post-LN 在残差路径上放了 LN，破坏了「恒等捷径」 | 深层梯度衰减，32 层以上训练不稳 |
| 残差连接 | 给梯度一条绕过子层的直达高速路 | 深层网络根本训不动 |
| 因果掩码 | 训练要并行、推理要自回归，两者形态不一致 | 训练时「偷看答案」，推理崩 |

---

## 三、我认为最有价值的 5 个「底层原理」

### 1. 约束降级（最重要的一条启发）

顺序是语言**必需**的，但 RNN 把它做成了**计算结构**（必须串行）。
Transformer 把它降级成一个**输入特征**（位置编码）。

> **一旦把结构性约束降级为数据特征，它就变得可并行、可组合、可外推。**

这是整个架构最漂亮的一步。RoPE 之所以能 4K 训练外推到 128K，正是因为位置被编码成了「相对旋转」这个代数结构，而不是「第几位」这个坐标。

### 2. 松弛可微

硬检索 = argmax（不可微）→ 软化成 softmax → 变成可梯度下降的软检索。

同一套路还有：Gumbel-Softmax、Straight-Through Estimator、MoE 的软路由、REINFORCE。
**凡是遇到「离散决策卡住了端到端训练」，先想能不能把它松弛成分布。**

### 3. 注意力 = 通信，FFN = 计算（这个区分能解释一半的现代 LLM 演进）

- Attention：参数少，**输入相关的动态权重**，负责「谁跟谁说话」
- FFN：占非 embedding 参数 ≈ 2/3，**静态权重**，被证明是模型的键值记忆库（存储事实知识）

MoE 只稀疏化 FFN 而不动 Attention，正是因为「知识是稀疏激活的，但路由必须稠密」。

### 4. 恒等捷径必须真的恒等

`output = x + Sub(LN(x))`（Pre-LN）而不是 `LN(x + Sub(x))`（Post-LN）。
差别在于：Pre-LN 的残差分支上**没有任何变换**，梯度可以无损直达；Post-LN 在捷径上插了个 LN，高速公路被设了收费站。

### 5. 门控即路由

SwiGLU 的 `x·W_gate`、LSTM 的遗忘门、Attention 的权重、MoE 的 router——**都是同一个 idea 的不同实例**：让系统自己学「什么该通过」。

> 凡是你想硬编码「if 条件 then 保留」的地方，都可以考虑换成一个可学习的门。

## 四、为什么要「除以 √d_k」（推导一遍，值得）

设 q、k 各分量独立、均值 0、方差 1：

```
q·k = Σ(i=1..d_k) qᵢkᵢ
Var(q·k) = Σ Var(qᵢkᵢ) = d_k · 1 = d_k     ⇒ 标准差 = √d_k
```

d_k=64 时，点积标准差约 8。输入到 softmax 的量级一大，输出就趋近 one-hot，梯度≈0。
**除以 √d_k 是把标准差（不是方差）压回 1**。

> 可迁移原则：**任何「多个独立贡献相加」的地方，都要检查方差会不会爆炸。**
> 加权融合、投票集成、多信号打分——同样的道理。

## 五、2017 → 2024 的演化逻辑（真正的启发所在）

| 原始 Transformer | 现代 LLM | 真实驱动力 |
|---|---|---|
| Encoder-Decoder | Decoder-only | 任务统一：生成即理解 |
| Post-LN | Pre-LN / RMSNorm | 深层可训练性 |
| ReLU | SwiGLU | 参数效率（多 33% 参数换更好收敛，净赚） |
| Sinusoidal | RoPE | 相对位置 + 长度外推 |
| 有 bias | 无 bias | 去掉冗余自由度 |
| Sinusoidal 加到输入 | RoPE 旋转 Q/K | 保结构变换 > 特征拼接 |
| MHA | GQA / MLA | 推理瓶颈从**算力**变成**显存带宽** |
| 稠密 FFN | MoE | 参数与推理成本解耦 |

### 关键洞察

**这些改动几乎都不是为了「更强」，而是为了「在固定算力/显存预算下更强」。**

- FlashAttention：**一个数学都没改**，只是做了 IO 感知的访存优化，就解决了 O(n²) 的内存瓶颈
- GQA：牺牲一点质量换 KV cache 缩小 8 倍，推理净赚
- RMSNorm：省掉一次归约计算，纯赚

> **当范式确立后，进步来自「精确测量真正的瓶颈并定点打击」，而不是堆规模。**
> 先问：瓶颈是 FLOPs？显存？带宽？IO？—— 测量错了，优化全白费。

## 六、可以迁移到工程/系统设计/做事上的 8 条原则

1. **约束降级**：能做成数据的，别做成结构（顺序 → 位置编码）
2. **松弛可微**：离散卡住训练/优化时，先想软化
3. **关注点分离**：寻址 vs 内容、通信 vs 计算、位置 vs 语义
4. **保留恒等捷径**：任何长链路都要有一条不受变换影响的旁路（兜底路径/快速通道）
5. **方差守恒**：多源汇总处控制尺度，否则非线性饱和
6. **门控代替硬规则**：让系统自己学「什么通过」
7. **瓶颈驱动优化**：先测量，再动手
8. **并行度换表达力**：FLOPs 不变的前提下，多头/多专家/多视角是「免费午餐」的主要来源

## 七、原文中值得商榷 / 需要更正的点（说明我确实读懂了）

1. §2.2 步骤 2 写 `S / d_k`，应为 `S / √d_k`（正文别处是对的，纯笔误）
2. §2.3 说「除以 √d_k 将**方差**压回 1」——不严谨，压回 1 的是**标准差**（方差原本是 d_k，除完后是 1，这个说法其实对；但表述易误导，准确说是「把点积的尺度归一化到单位量级」）
3. §6.1 把 LayerNorm 归因于「解决内部协变量漂移（ICS）」——**这是 2015 年的旧叙事，已被后续研究修正**。现代观点（如 Pre-LN 的分析）认为 LN 的主要作用是**稳定梯度尺度、改善损失景观的 Lipschitz 性质**，而不是字面意义上减少 ICS
4. §4 说 FFN「约占 2/3 参数」——仅在 **不计 embedding/lm_head、且 d_ff=4×d_model** 时成立。现代大模型词表动辄 15 万+，embedding + lm_head 的参数量常常与 FFN 同量级甚至更大
5. §8 表格中「O(1) 步跨越任意距离」与「每步 O(n²)」并不矛盾，但要注意：**信息路径短 ≠ 远距离信息被有效利用**，后者高度依赖位置编码的质量

## 九、三句话总结（给未来的自己）

1. **Transformer 的本质是把「序列处理」重构成「可微的并行内容寻址检索」。**
2. **它牺牲了顺序的内建性，换来了完全并行；之后所有的组件都是在偿还这笔债、或是在兑现这笔收益。**
3. **架构演化的主线不是「更强」，而是「找到真正的瓶颈，然后把非瓶颈的资源省下来给瓶颈」。**
