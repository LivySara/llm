# 父子组件相互传值

- 方案一：子组件用来更新数据，通过事件input/change等，从而父组件可拿到数据
- 方案二：v-model方法，需要维护子组件内的数据，什么时候数据同步给父组件，什么时候数据传给父组件

# 组件拆分

- 哪一层组件拥有这份数据？哪一层组件只负责输入？


```
700 行组件
    ↓

    ↓

```
