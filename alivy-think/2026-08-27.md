# 要点

- Node.js 提供了创建网络服务器的能力，你的程序调用 http.createServer() + listen() 后，这个 Node.js 程序就可以作为一个 HTTP 服务器运行。
- http服务器本质：监听TCP端口，接收浏览器/客户端发来的http协议报文，解析请求，返回http响应报文
- dns 将域名翻译成 IP 地址
- DNS 解决“去哪台机器”，端口解决“这台机器上的哪个服务”
- 服务器可以运行多个服务；是否一个服务器只放一个服务，是架构和部署策略问题，不是 HTTP/Node.js 的硬性规定
- IP 负责“送到哪台机器”，TCP 负责“送过去的数据怎么可靠、有序地传输”。
- 链路层：相邻往里哦节点之间的一跳传输

- TCP 把数据给服务器，那服务器怎么知道给谁处理？
> 官方ans：TCP 数据里有目标端口，服务器操作系统根据目标端口找到对应的 Socket/进程，再把数据交给对应的应用程序
- res.end() 不能直接接收一个 JavaScript 对象 {}。
> res.end() 是在发送 HTTP Response Body；HTTP 最终传输的是字节数据，而不是 JavaScript 对象。

# 检验

① Node.js 怎么启动服务器？
- 个人：http依赖中 createServer + listen
- 官方：Node.js 通过 node:http 模块的 http.createServer() 创建 HTTP Server，再通过 server.listen() 开始监听指定端口，等待客户端连接。
② 为什么浏览器能找到它？
- 个人：dns 解析 服务器地址，网络层找到ip位置
- 官方：客户端根据 URL 确定目标主机和端口；如果使用域名，会先通过 DNS 将域名解析为 IP，然后通过网络把请求发送到这个 IP 的对应端口。
③ 请求怎么进入 Node.js？
- 个人：请求时携带的端口号，识别对应的服务端上应用程序
- 官方：客户端连接服务器的 IP + 端口；操作系统根据目标端口，将对应连接交给正在监听该端口的进程（例如 Node.js）。Node.js 的 HTTP Server 再解析 HTTP 请求，并触发 createServer 注册的请求处理函数。
④ Node.js 怎么判断 URL？
- 官方：在 Node.js 原生 http 模块里，就是通过请求对象 req 来判断 URL。
⑤ 怎么读取参数？
- 官方：URL 查询参数通过 URL / searchParams 读取；POST 等请求的 Body 参数通过 req 请求流读取。
⑥ 怎么查询数据库？
- 官方：Node.js 自己不会“查询数据库”，而是通过数据库驱动/客户端，向数据库服务器发送查询请求，然后拿到结果。
⑦ 怎么返回 JSON？
- 无
⑧ 前端怎么拿到 JSON？
- 无
⑨ 如果中间有 Gateway，会发生什么？
- 官方：Gateway 作为客户端和后端服务之间的中间层，接收客户端请求，根据路由规则将请求转发给对应的后端服务；后端返回响应后，Gateway 再将响应返回给客户端。
⑩ 如果请求失败，怎么定位是哪一层出问题？
- 官方：
```
浏览器
 ↓
① DNS
 ↓
② 网络 / IP
 ↓
③ TCP / Port
 ↓
④ Gateway / Proxy
 ↓
⑤ Node.js HTTP Server
 ↓
⑥ 路由
 ↓
⑦ 业务代码
 ↓
⑧ 数据库 / Redis / 第三方服务
```
